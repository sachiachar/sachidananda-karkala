VeriClaims AI

An agent swarm decides returns, insurance cover and claims on evidence instead of trust.

  • Video is sealed on the device with a hash chain and a signature; integrity is always a cryptographic verdict, never an LLM's opinion.
  • A deterministic floor: if the agent skips a step, code fills it, so the agentic result is never worse than the rule-based one.
More detail
  • A second agent swarm researches new fraud tactics every night and verifies each one on the web before it enters a versioned knowledge base.
  • Tenants integrate through one REST API with idempotent requests and HMAC-signed callbacks carrying the full audit trail.

Anvaya

An AI companion that helps families find what a loved one left behind — and hands it over safely.

  • Fifteen agents run inside budgets behind one gateway; a guardian can check, steer, pause or block every loop.

InsideEdge

An always-on lobby TV channel for a company with 60+ offices, composed live by a crew of AI agents in each office's own language.

  • Reporters pitch, an Editor per office plans the rundown, a Producer writes native-language copy, and a Gatekeeper approves every segment.
  • Employee posts go on air in under 90 seconds; a person can override or kill any segment in seconds.
More detail
  • Hard editorial rules run in code, not in the prompt; the safety check runs in parallel with rendering, so it adds no delay.
  • A day-one spike measured ~2 s segment compiles and found that no render font could draw Japanese — so CJK text moved to an HTML overlay.

Identity & trust · Database-enforced rules · Serverless AWS

Vouch

A professional network where standing comes only from work records that other people signed.

  • Self-endorsement is impossible at the schema level, and history cannot be rewritten — the rules live in Postgres, not in application code.
  • Specification-first testing found 21 defects before users did; one profile query went from 531 ms to 1.2 ms.
More detail
  • Ed25519-signed records that anyone can verify without calling the service again.
  • A ~2 MB Rust API on Lambda, a database that scales to zero, and no NAT gateway — designed around an idle bill near zero.

How I work

Six principles behind every system

01

Put trust where it can't be forgotten

Enforce rules in the database, in cryptography and in permissions — not in prompts or the UI.

02

AI proposes, people decide

Human approval is a structural gate, not a checkbox at the end.

03

A deterministic floor under every agent

If the model skips a step, code fills it. The agentic result is never worse than the rule-based one.

04

Measure knowledge before you use it

Score it, cite it, and let systems refuse low-confidence work.

05

Centralise the platform, keep the edges pluggable

One identity, one gateway, one cost centre — with swappable models and workflows.

06

Say what isn't built

Known gaps are written down as specifications, and AI abstains where it lacks evidence.
